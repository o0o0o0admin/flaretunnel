Tests

(a) Account validity

Checks every Cloudflare account token via the live analytics endpoint (a success entry means the token works).

(b) Rotation check

Reads the configured rotation mode and asserts the probed workers span more than one distinct exit IP.

(c) Tunneling check

Passes when at least one probed worker answers with an origin IP (traffic reaches the public internet).

(d) Exit IP lookup

Enriches the exit IP of the selected worker (from the probe above) via free IP-info providers with fallbacks.
